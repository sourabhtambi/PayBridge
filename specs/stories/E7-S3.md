# E7-S3: Settlement files screen

- **Epic:** E7 - Settlement
- **Layer:** UI
- **Group:** H
- **Depends on:** E7-S2, E1-S4

## Description

Adds the admin settlement screen: file list, download and run-now.

## Acceptance Criteria

1. The list shows business date, kind, row count, checksum and a download link per file, and 'No settlement files yet' when empty (feature F115)
2. Run now posts to /settlement/run and shows the result, and a repeated run shows 'Primary file for this date already exists. Late entries were written to a follow-up file.' (feature F116)
3. Loading shows skeleton rows and an error shows a retry banner (feature F117)
4. Each download link has an accessible name containing the business date and kind (feature F118)
