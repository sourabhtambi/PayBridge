# E7-S2: Daily settlement job and settlement API

- **Epic:** E7 - Settlement
- **Layer:** API
- **Group:** G
- **Depends on:** E7-S1

## Description

Schedules the daily run at 23:59 IST and exposes admin endpoints to trigger a run and to list and download files.

## Acceptance Criteria

1. The scheduler computes the next run as 23:59 Asia/Kolkata and fires once per business day under an injected clock (feature F111)
2. POST /settlement/run as admin returns 201 for a first run (primary), and 200 with kind followup or a message that the primary exists for a repeated run (feature F112)
3. GET /settlement/files lists files with id, business_date, kind, row_count, checksum, and GET /settlement/files/{id} returns the CSV as text/csv, with 404 for an unknown id (feature F113)
4. Customer and ops roles receive 403 on every settlement endpoint (feature F114)
