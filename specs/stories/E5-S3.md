# E5-S3: Customer refund request UI

- **Epic:** E5 - Refunds
- **Layer:** UI
- **Group:** G
- **Depends on:** E5-S1, E3-S3

## Description

Adds the refund request action and refund status display to the payment detail page.

## Acceptance Criteria

1. The Request refund button appears only on COMPLETED payments that have no refund (feature F083)
2. Clicking the button disables it while the request is pending and then shows the text 'Refund requested' (feature F084)
3. A 409 shows 'A refund was already requested for this payment' (feature F085)
4. The detail page shows the refund state, and the reason code as text when the refund is REJECTED or FAILED (feature F086)
