# E5-S4: Admin refund queue UI

- **Epic:** E5 - Refunds
- **Layer:** UI
- **Group:** G
- **Depends on:** E5-S2, E1-S4

## Description

Gives admins a queue of requested refunds with approve and reject actions.

## Acceptance Criteria

1. The queue lists REQUESTED refunds with payment id, amount in Indian grouping and requester, and shows 'No refunds pending' when empty (feature F087)
2. Approve and reject buttons call their endpoints and the row updates to the final state text (feature F088)
3. A 409 shows 'This refund was already decided' (feature F089)
4. Loading shows skeleton rows, errors show a retry banner, and buttons have names that include the payment id for screen readers (feature F090)
