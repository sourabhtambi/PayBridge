# E9-S2: Performance verification

- **Epic:** E9 - Cross-cutting Quality (NFRs)
- **Layer:** Service
- **Group:** F
- **Depends on:** E2-S4, E2-S3

## Description

Verifies NFR-01 and NFR-02 with automated load tests on SQLite WAL.

## Acceptance Criteria

1. POST /payments p95 latency is 300 ms or less across 200 requests (feature F132)
2. The system sustains at least 20 payments per second for 10 seconds with all payments persisted (feature F133)
3. No SQLITE_BUSY errors occur under load and all payments reach a terminal state within 60 seconds after the load stops (feature F134)
