# E1-S1: Domain types, rail config and routing rules

- **Epic:** E1 - Foundation and Role Switch
- **Layer:** Types
- **Group:** A
- **Depends on:** none

## Description

Defines the shared domain enums, the money helpers and the rail routing bands. Everything downstream depends on these rules, so they are specified at paise granularity with inclusive upper bounds as in BRD section 5.3.

## Acceptance Criteria

1. route_rail returns UPI for 100 and 10,000,000, IMPS for 10,000,001 and 20,000,000, NEFT for 20,000,001 and 50,000,000, RTGS for 50,000,001 and 1,000,000,000,000 paise (feature F001)
2. Amounts 0, -1, 1 and 99 paise raise a validation error with code AMOUNT_BELOW_MINIMUM, and 100 is accepted (feature F002)
3. The rupee-to-paise helper converts the string '1,00,000.50' to the integer 10000050 using Decimal and rejects '1.005' (three decimals) and non-numeric input (feature F003)
4. PaymentState, RefundState, ReconStatus and Role enums contain exactly the values in the BRD, and the transition table rejects COMPLETED to SUBMITTED and FAILED to COMPLETED (feature F004)
5. mypy src/ passes with zero errors and no field named *_paise is annotated float (feature F005)
