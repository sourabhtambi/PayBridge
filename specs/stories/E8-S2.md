# E8-S2: Admin dashboard screen

- **Epic:** E8 - Admin Dashboard
- **Layer:** UI
- **Group:** I
- **Depends on:** E8-S1, E5-S4, E7-S3

## Description

Builds the dashboard screen: volume tiles, status breakdown, refund queue and settlement reports.

## Acceptance Criteria

1. Volume tiles per rail show counts and totals formatted like 'Rs 1,00,000.50', and the status breakdown shows text labels with numbers (feature F124)
2. A date with no activity shows zero values with 'No activity for this date' (feature F125)
3. The embedded refund queue supports approve and reject and updates the tile after action (feature F126)
4. A tile-level error shows a retry control for that tile only, and a date picker defaults to today in IST (feature F127)
