# E1-S4: Role switcher UI

- **Epic:** E1 - Foundation and Role Switch
- **Layer:** UI
- **Group:** D
- **Depends on:** E1-S3

## Description

Builds the application shell with the role selector, customer picker and role-aware navigation. It provides the API client that attaches the role headers to every request.

## Acceptance Criteria

1. The header contains a select labelled 'Role' with options Customer, Ops and Admin, operable by keyboard (feature F016)
2. The customer picker is visible only when the role is Customer and is populated from GET /customers (feature F017)
3. Every API request carries X-Role and X-Customer-Id from the current selection, and the selection persists across a page reload via localStorage (feature F018)
4. Navigation shows Payments for Customer, Reconciliation and Stuck payments for Ops, and Dashboard, Settlement and Simulation for Admin, and no other items (feature F019)
