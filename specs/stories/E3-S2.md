# E3-S2: My payments list

- **Epic:** E3 - Customer Payment Screens
- **Layer:** UI
- **Group:** F
- **Depends on:** E2-S3, E1-S4

## Description

Shows the customer's payments with state and reason code in a responsive, accessible table that covers empty, loading and error states.

## Acceptance Criteria

1. Each row shows amount formatted like 'Rs 1,00,000.50', rail, state as text, reason code when FAILED, and created time (feature F043)
2. Empty shows 'No payments yet' with a link to the new payment form, loading shows skeleton rows, and an API error shows a retry banner with the failure message that refetches on click (feature F044)
3. Each row links to /payments/{id}, and the table has a caption and is fully keyboard navigable (feature F045)
4. State is conveyed by a text badge, and the badge text exists for CREATED, SUBMITTED, COMPLETED and FAILED independent of colour (feature F046)
