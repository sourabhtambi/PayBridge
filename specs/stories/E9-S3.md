# E9-S3: Accessibility verification

- **Epic:** E9 - Cross-cutting Quality (NFRs)
- **Layer:** UI
- **Group:** J
- **Depends on:** E8-S2, E7-S3, E6-S3, E5-S4, E4-S5, E3-S3

## Description

Verifies NFR-07 (WCAG 2.1 AA) across all screens with automated and keyboard-only checks.

## Acceptance Criteria

1. axe-core reports zero serious or critical violations on every screen (feature F135)
2. A customer can create a payment and open its detail using only the keyboard (feature F136)
3. Text and interactive elements meet contrast ratio 4.5:1, verified against the design tokens (feature F137)
4. No status is conveyed by colour alone: each status element has a text label (feature F138)
