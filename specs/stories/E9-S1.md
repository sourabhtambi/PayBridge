# E9-S1: Sensitive data masking in logs

- **Epic:** E9 - Cross-cutting Quality (NFRs)
- **Layer:** Config
- **Group:** F
- **Depends on:** E2-S3

## Description

Implements NFR-03 with a logging filter that masks beneficiary names and account numbers in every log record.

## Acceptance Criteria

1. The logging filter replaces a beneficiary value with a masked form such as 'R*** K***' in message and extra fields (feature F128)
2. Digit sequences of 9 to 18 digits are masked to the last four digits (feature F129)
3. Captured logs from a full run of payment creation, worker processing and refund flow contain no beneficiary text (feature F130)
4. Exception tracebacks logged for failures are also masked (feature F131)
