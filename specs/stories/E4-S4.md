# E4-S4: Stuck payment detection and ops API

- **Epic:** E4 - Retry and Failure Simulation
- **Layer:** API
- **Group:** H
- **Depends on:** E4-S3, E1-S3

## Description

Flags payments stuck in SUBMITTED for more than 5 minutes and lists them for ops review.

## Acceptance Criteria

1. A payment in SUBMITTED for 5m01s is flagged stuck and one at 4m59s is not (feature F065)
2. GET /ops/stuck-payments as ops or admin returns the stuck payments with age_seconds, and a customer receives 403 (feature F066)
3. Flagging appends one PAYMENT_FLAGGED_STUCK event and running detection repeatedly does not append duplicates (feature F067)
4. A flagged payment that reaches COMPLETED or FAILED no longer appears in the stuck list (feature F068)
