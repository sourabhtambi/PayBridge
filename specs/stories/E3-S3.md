# E3-S3: Payment detail with timeline and polling

- **Epic:** E3 - Customer Payment Screens
- **Layer:** UI
- **Group:** F
- **Depends on:** E2-S3, E1-S4

## Description

Presents a single payment with its event timeline and attempts, and polls for updates while the payment is non-terminal.

## Acceptance Criteria

1. The detail page shows the payment fields, an event timeline in chronological order and an attempts table with attempt number and outcome (feature F047)
2. While the state is CREATED or SUBMITTED the page polls GET /payments/{id} every 2 seconds, and stops once COMPLETED or FAILED (feature F048)
3. FAILED shows the reason code as text, and an unknown id shows a not-found message with a back link to /payments (feature F049)
4. Loading shows a skeleton timeline, and at a 375px viewport the page has no horizontal scroll (feature F050)
