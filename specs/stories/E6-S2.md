# E6-S2: Reconciliation API

- **Epic:** E6 - Reconciliation
- **Layer:** API
- **Group:** F
- **Depends on:** E6-S1, E1-S3

## Description

Exposes reconciliation run, the unmatched queue and resolution with a note. Nothing is auto-corrected.

## Acceptance Criteria

1. POST /reconciliation/run with a statement_date as ops or admin returns 200 with counts per status (feature F097)
2. GET /reconciliation/unmatched returns unresolved non-matched results and supports ?status= and ?rail= filters (feature F098)
3. POST /reconciliation/{id}/resolve with a note sets resolved true and stores the note, an empty note returns 422, and resolving again returns 409 (feature F099)
4. A customer calling any reconciliation endpoint receives 403 (feature F100)
5. Resolving an entry changes neither the payment record nor any amount_paise value (feature F101)
