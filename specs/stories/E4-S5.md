# E4-S5: Simulation controls and stuck payments screens

- **Epic:** E4 - Retry and Failure Simulation
- **Layer:** UI
- **Group:** I
- **Depends on:** E4-S1, E4-S4

## Description

Adds the admin simulation screen and the ops stuck-payments screen.

## Acceptance Criteria

1. The Simulation screen shows one card per rail with a mode radio group, a reason-code select for permanent failure and a rate input for transient, and saving calls PUT and shows a confirmation (feature F069)
2. A transient rate outside 0 to 1 shows a field error and does not call the API (feature F070)
3. The Stuck payments screen lists payment id, rail, amount and age, shows 'No stuck payments' when empty, and a retry banner on error (feature F071)
4. All simulation form controls have programmatic labels and are operable by keyboard alone (feature F072)
