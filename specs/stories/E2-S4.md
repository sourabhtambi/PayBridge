# E2-S4: Outbox worker with mock rail adapters (success mode)

- **Epic:** E2 - Payment Creation and Idempotency
- **Layer:** Service
- **Group:** D
- **Depends on:** E2-S1

## Description

Adds the in-process asyncio worker that polls the outbox and submits to the mock rail adapters, recording attempts and events. This story covers the happy path; retry and failure come later.

## Acceptance Criteria

1. The worker moves a CREATED payment to SUBMITTED then COMPLETED, records one attempt with outcome success, and appends PAYMENT_SUBMITTED and PAYMENT_COMPLETED events (feature F034)
2. UPI, NEFT, RTGS and IMPS adapters implement one RailAdapter interface, and submitting the same payment id twice returns the same rail reference (feature F035)
3. The worker starts as an asyncio task in the FastAPI lifespan and stops cleanly on shutdown without pending-task warnings (feature F036)
4. A processed outbox row is marked SENT and is not processed again on later polls (feature F037)
