# E4-S1: Mock rail simulation modes and admin API

- **Epic:** E4 - Retry and Failure Simulation
- **Layer:** API
- **Group:** E
- **Depends on:** E2-S4, E1-S3

## Description

Lets an admin set each mock rail to success, permanent failure with a reason code, or a transient failure rate. The adapters honour the mode deterministically in tests via a seeded random source.

## Acceptance Criteria

1. PUT /admin/simulation/{rail} accepts mode success, permanent_failure with reason_code, or transient with transient_failure_rate in [0,1], returns 200 echoing the config, and a rate of 1.5 returns 422 (feature F051)
2. GET /admin/simulation returns the config of all four rails, all defaulting to success (feature F052)
3. Non-admin roles calling either simulation endpoint receive 403 (feature F053)
4. In permanent_failure mode the adapter raises PermanentRailError carrying the configured reason code (feature F054)
5. With a seeded RNG, transient rate 1.0 raises TransientRailError on every call and rate 0.0 never does over 100 calls (feature F055)
