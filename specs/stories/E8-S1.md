# E8-S1: Dashboard summary API

- **Epic:** E8 - Admin Dashboard
- **Layer:** API
- **Group:** H
- **Depends on:** E5-S2, E7-S2, E4-S2

## Description

Provides the aggregates the admin dashboard needs for one IST business date.

## Acceptance Criteria

1. GET /dashboard/summary?date= returns per-rail payment count and total_paise for that IST date (feature F119)
2. The summary includes counts for CREATED, SUBMITTED, COMPLETED and FAILED (feature F120)
3. The summary includes the pending refund list and the settlement files for the date (feature F121)
4. A date with no activity returns 200 with zero values, not 404 (feature F122)
5. Non-admin roles receive 403 (feature F123)
