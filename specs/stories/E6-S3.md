# E6-S3: Reconciliation screens for ops

- **Epic:** E6 - Reconciliation
- **Layer:** UI
- **Group:** G
- **Depends on:** E6-S2, E1-S4

## Description

Adds the reconciliation run form, result summary and unmatched queue with resolve-with-note.

## Acceptance Criteria

1. The run form has a labelled date input and shows counts per status after a successful run (feature F102)
2. The unmatched queue shows status as text, rail and both amounts, and shows 'Nothing to reconcile' when empty (feature F103)
3. The resolve dialog requires a note, shows a field error when empty, and on success removes the row from the queue (feature F104)
4. Loading shows skeleton rows, errors show a retry banner, and the dialog traps focus and returns it to the trigger on close (feature F105)
